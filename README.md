# MEEG_source_imaging
Hands-on MEEG source imaging

## Hands-on groups

Participants will work in two parallel groups using the same EEG dataset
and comparable source-reconstruction settings.

### Group 1 — Brainstorm

➡️ [Brainstorm materials](Brainstorm/README.md)

### Group 2 — MNE-Python

➡️ [MNE-Python materials](MNE/README.md)

At the end of the hands-on, the two groups will compare their results,
with particular attention to source localization around the N170,
ROI time series, inverse method and regularization.
